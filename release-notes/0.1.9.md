- **Account keys:** a key line that GhostRack writes now starts with `ghostrack-account-seed-v1:`. Keys saved with `gigahost-account-seed-v1:` keep working, and the same key under either label is the same account.
- GhostRack 0.1.8 and earlier read only `gigahost-account-seed-v1:`. To use a key line written by a newer client there, update the app, or change the start of the line to `gigahost-account-seed-v1:`.
