GhostRack is the new name of the Gigahost desktop app.

- **Linux:** the `ghostrack` Debian package replaces the `gigahost` package, so installing it removes Gigahost 0.1.7.
- **Windows and macOS:** GhostRack 0.1.8 installs beside Gigahost 0.1.7. It is best to remove Gigahost after GhostRack has started for the first time, and not to run both apps at once.
- Saved settings and pending operations stay where they were, and GhostRack keeps using them.
